# DONE.md — 完成條件定義

> 每個專案必須有這份檔案，放在專案根目錄。
> 這份檔案定義「什麼叫做完成」，由人工撰寫，AI 不得修改。
> 沒有這份檔案，`loop.sh` 拒絕啟動。

---

## 專案資訊

| 欄位 | 值 |
|------|-----|
| 專案名稱 | `{project}` |
| 服務名稱 | `{project}.service` |
| 服務 Port | `{port}` |
| 部署路徑 | `/opt/{project}` |
| 健康端點 | `http://127.0.0.1:{port}/api/v1/health` |

---

## 完成條件（Gates）

以下每一條都必須是**機器可驗證**的。
不可以寫「程式碼要乾淨」「UI 要好看」這種人工判定的條件。
人工判定的項目寫在下方「人工驗收」區，不進入自動迴圈。

### G1 — 靜態檢查

```
ruff check . --quiet
black --check . --quiet
```

通過標準：兩個指令 exit code 皆為 0。

### G2 — 單元測試

```
pytest -q --tb=short
```

通過標準：exit code 0，且測試數量 > 0（空測試不算通過）。

### G3 — 服務存活

```
systemctl is-active {project}
```

通過標準：輸出為 `active`。

### G4 — 健康端點

```
curl -fsS --max-time 5 http://127.0.0.1:{port}/api/v1/health
```

通過標準：HTTP 200，且回應 JSON 含 `"status": "ok"`。

### G5 — 前端資源落地

所有 `templates/` 與 `static/` 下的檔案，不得出現任何外部資源引用。

禁止出現的字串：
```
cdn.
cdnjs
unpkg
jsdelivr
fonts.googleapis
fonts.gstatic
https://
http://
```

例外白名單（寫在 `.verifyignore` 中，需人工核准）：
```
（預設為空，任何例外都必須人工加入並註明理由）
```

通過標準：掃描結果為 0 筆命中。

### G6 — 安全基準

- 程式碼中不得出現硬編碼憑證（密碼、token、API key）
- 不得出現 `rm -rf` 或 `rm -f`
- 不得出現 `shell=True` 搭配外部輸入
- `.env` 不得被 git 追蹤
- 生產環境設定中 `/docs` 與 `/redoc` 必須關閉

通過標準：掃描結果為 0 筆命中。

## 硬性退出條件（Hard Exit）

迴圈遇到以下任一情況，**立即停止並呼叫人工**，不再重試：

| 條件 | 說明 |
|------|------|
| 嘗試次數達上限 | 預設 3 次（見 `loop.conf` 的 `MAX_ATTEMPTS`） |
| 連續兩次相同錯誤 | 代表 AI 在原地打轉，換方向也無效 |
| 觸碰受保護檔案 | `docs/`、`prompts/`、`.env`、`DONE.md` 本身 |
| deploy-guard 否決 | 安全 agent 攔截，人工未核准前不得繼續 |
| 單次執行超時 | 預設 900 秒（見 `loop.conf` 的 `TIMEOUT_SEC`） |
| 回滾已觸發 | `rollback.sh` 執行過後，迴圈必須停止待人工檢視 |

## 人工驗收（不進入自動迴圈）

這些項目由人工在迴圈通過後檢視，**不是** AI 自動判定的完成條件：

- [ ] UI 視覺符合設計語言（色彩、字型、間距）
- [ ] 互動流程順暢，無多餘點擊
- [ ] RWD 在手機與桌機皆正常
- [ ] 無障礙基本規範（alt text、對比度）
- [ ] 首屏載入 3 秒內
- [ ] 語系切換正常（英 > 繁中 > 簡中），Cookie 記憶有效

> 註：UI/UX 是這個專案的重點，但它無法被 shell script 驗證。
> 迴圈負責把「能跑、安全、沒壞」自動搞定，
> 把你的時間留給「好不好看、好不好用」這件真正需要你的事。
